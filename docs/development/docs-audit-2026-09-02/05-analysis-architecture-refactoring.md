# Docs audit — `docs/analysis/`, `docs/architecture/`, `docs/refactoring/`

Auditor scope: 46 markdown files. Repository at `master` / `b8884687` (2026-09-02). Read-only; no repo file was modified.

## Executive summary

1. **`docs/analysis/decompiler/README.md` — the file `README.md` and `docs/README.md` both advertise as *the* decompiler documentation — is not documentation of Glaurung's decompiler.** 583 lines, of which roughly 470 are a 2025-era survey of Ghidra/RetDec/Reko/Fernflower/ILSpy with star ratings, invented benchmark numbers, a "2025 Q1-Q2 / 2026+ (quantum algorithm recovery)" roadmap, and Rust/Python API examples (`glaurung::decompiler::Decompiler`, `glaurung.Decompiler(engine="ghidra")`) for APIs that do not exist. Only two sections are real: the JSON output schema (added 2026-08-29) and the CLI flag paragraph. **This is the single worst doc/code divergence in my scope and it sits on the most-linked path.**
2. **`docs/analysis/decompiler/pipeline.md` is honestly self-labelled historical, and is off by ~3x.** It describes 21 numbered passes at commit `adde50b` (2026-04-24). Ground truth today: **57 distinct `src/ir::*` modules are invoked from `src/python_bindings/ir*`**, the AST pipeline in `src/python_bindings/ir/pipeline.rs` has 20 named `pass!` groups, and there is a second ~30-step render-preparation chain in `src/python_bindings/ir/decbench_render.rs` that pipeline.md does not know exists at all.
3. The other eight `docs/analysis/decompiler/*.md` files are dated evidence checkpoints (2026-07-27 → 2026-08-08). They are accurate as records and worth keeping; they are not guidance and no one should read them as such.
4. **`docs/analysis/disassembly/README.md` and `docs/analysis/language-detection/README.md` are the two best documents in my scope** — I verified every concrete claim in both against `python/glaurung/cli/commands/disasm.py` and `src/triage/compiler_detection.rs` and found zero errors, including the deliberately unflattering ones ("`--comments` returns no comment" — `_get_instruction_comment` literally `return None`).
5. `docs/analysis/lifting/` (525 lines on llvm-mctoll/RetDec/mcsema) and `docs/analysis/symbols/` (2,090 lines) are pre-implementation surveys and plans for a layout (`src/triage/symbols/`, `src/triage/suspicious.rs`) that **never existed**; the real code is `src/symbols/`. RetDec is not integrated; `reference/retdec` does not exist.
6. **`docs/architecture/PERSISTENT_PROJECT.md` is genuinely current and load-bearing** — schema version `1`, `function_identity` + `glaurung-structural-v1`, fail-closed on version mismatch, all verified. One defect: its worked example writes to `/tmp`, which CLAUDE.md forbids.
7. **CLAUDE.md and the `rust-data-model-creator` agent both point at `docs/data-model/`, which does not exist** — it is `docs/architecture/data-model/`. The agent instructs six times to read a path that resolves to nothing.
8. **`python/glaurung/kb/` does not exist either** (CLAUDE.md's map claims it). The knowledge base is `python/glaurung/llm/kb/` — 27 modules under the *LLM* subtree, which is an architectural fact the rewrite should decide about deliberately.
9. `docs/architecture/data-model/` is 8 of 10 files historical AI-roundtable proposals/critiques (CLAUDE/GEMINI/GPT5/GROK4). I traced their recommendations into `src/core/address.rs`: **partially adopted** (`width`→`bits` yes, drop `confidence` yes, restrict `AddressKind` to VA/RVA/FileOffset **no** — all six variants shipped).
10. **`docs/refactoring/` (7 numbered plans, 2026-08-13) is an orphaned portfolio.** One inbound link in the whole repo; zero commits reference it; zero of the seven target directory layouts were built as specified. Progress on the *underlying* problem is real but is being driven by a different, live mechanism (`tools/fitness_report.py` + `tools/fitness_baseline.json` + `python/tests/test_large_module_review.py`, per `docs/design/decompiler-roadmap.md` §"Code quality, composition, and file-size program").
11. Scored against code: **P3 (CFG) largely executed** (`cfg.rs` 7,125 → 1,992 with 19 submodules), **P7 partially** (`explore.rs` 3,617 → 1,768), **P2/P4 partially** (subdirs exist, target names don't), **P1/P5/P6 not started** (`windows.py` unchanged at 4,027; `xref_db.py` *grew* 3,434 → 3,557; no `kb/schema|storage|repositories`). `lift_x86.rs` grew 8,556 → 9,556.
12. The `docs/refactoring/*/README.md` exit-evidence sections are the highest-value prose in my scope and would be lost on a delete — they are the only written statement of what "done" means for each boundary.
13. `docs/architecture/IDA_GHIDRA_PARITY.md` is a 182-line checklist whose banner disowns itself; ~35 of its CLI claims I spot-checked all resolve to real subcommands, but its "Demo loop status" and "Phase 5 launch" framing is dead product language.
14. Net recommendation for the rewrite: **1 file survives as-is (PERSISTENT_PROJECT.md), 2 survive with edits (disassembly, language-detection READMEs), 5 are rewritten, and 34 are archived as dated records.** Four are deletable outright.
